## 5. 事实、推断与不确定性

### 事实

- 以上所有 pass/fail 数字直接来自当前工作区最终重跑的 JSON 文件。
- `Info.plist` 实际解析值为 `CFBundleIdentifier=io.github.inostarlin-passion.Fovelle`、`CFBundleName=Fovelle`、`CFBundleExecutable=Fovelle`、版本 `0.1.0`。
- 指定 PNG 与 `resources/Fovelle.png` 完全一致。
- README 和 About 页均明确标注了来自 `jdpurcell/qView` 的部分提交及 jdpurcell 署名。

### 推断

- 5 次启动样本足以作为本次小型回归门槛，但不足以代表高并发、超大图片或长时间运行负载。
- 代码路径与 Qt 官方 last-window 语义结合后，可以判定生产配置会在最后窗口关闭时请求退出；单元测试刻意避免让测试 runner 自身提前退出。

### 不确定性与后续人工项

- 未执行签名、公证、Finder/Dock 缓存刷新和跨 macOS 版本人工视觉验收。
- 未对 GitHub Release API 发起真实升级请求；测试构建关闭自动联网检查。
- 系统探针的网络/磁盘主机计数可能含后台活动；完整原始尾部保存在 `system.json`。
- 原生 Cocoa 全屏的物理键盘事件没有在自动化环境中稳定复现；单元测试覆盖了 Escape key binding 和实际生产 shortcut 分支，建议在目标用户环境人工按键确认。
- qView 仓库页面显示 `jdpurcell/qView` 是 `jurplel/qView` 的 fork，并包含 GPLv3 许可证；本次署名只陈述“部分提交来源”，没有据此推断每一行代码或每个功能的作者归属。
