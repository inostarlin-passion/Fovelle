## 3. 实现结果与根因闭环

### 3.1 WebP/AVIF 方向

根因是两条读取链路的元数据处理不一致：Qt 路径设置了 `QImageReader::setAutoTransform(true)`，原生 fallback 却使用不带 options 的 `CGImageSourceCreateImageAtIndex`，因此绕过了方向元数据。

修复内容：

- `src/qvcocoafunctions.mm` 使用 `CGImageSourceCreateThumbnailAtIndex`。
- 传递 `kCGImageSourceCreateThumbnailFromImageAlways=true` 和 `kCGImageSourceCreateThumbnailWithTransform=true`。
- 从 Image I/O properties 读取源图最大宽高，把最大像素尺寸设为源图长边，保持原有 full-resolution 语义而不额外降采样。
- 移除旧的上下翻转：Image I/O thumbnail 已完成方向归一化，再次翻转会把正确结果倒置。
- WebP 测试用 EXIF RightTop fixture 断言 3×2 尺寸和四个角点；AVIF 测试用 `irot` fixture 断言 3×2 尺寸；两者还分别通过 `QVImageLoader` 验证最终 loader 输出。

### 3.2 全屏缩放连续性

根因是 `zoomAbsolute()` 在第一次手动缩放时清空 `calculatedZoomMode`；即使下一步逆向滚轮使 `zoomLevel` 数值回到原 fit 值，模式仍为空。窗口 resize 时 `fitOrConstrainImage()` 因此不重算 fit。

修复内容：

- `QVGraphicsView` 保存最近一次 sticky calculated mode（ZoomToFit/FillWindow）及其计算比例。
- 手动缩放回到该比例时，在浮点容差内恢复 mode；用户停留在其他比例时不恢复。
- resize/fullscreen 发生前，若当前比例仍是最近一次 calculated 比例，则恢复 mode，再按新 viewport 执行 `recalculateZoom()`。
- 换图、显式关闭 calculated mode 或选择 OriginalSize 时清空旧候选，避免跨图片误恢复。
- 新增真实 Cocoa fullscreen enter/exit 测试和真正手动比例 resize 测试。

### 3.3 保留的兼容性行为

- window icon 仍按既有修复清空，bundle/Finder/Dock icon 资源保留。
- 普通 mouse wheel 使用一个离散步长；touchpad/touchscreen fractional 输入仍按 delta 计算。
- WebP/AVIF native fallback、扩展/MIME 注册和 Settings → Formats 共用同一能力集合，`.avifs` 别名继续存在。

## 8. 已知限制

- 单元测试直接验证方向像素；系统 probe 只验证带方向文件可启动且无 Error 3，不把启动成功当作像素方向证明。
- Image I/O 的 AVIF 能力依赖 macOS UTI；在不支持 `public.avif` 的旧系统上，代码会保留不可读语义。
- 本次负载是小型 fixture，时间指标不是任意超大图片完整解码耗时的上界；大图专项性能测试应另建目标负载。
- 标题栏 icon 的系统测试通过 Qt window property、bundle 资源和集成检查验证，没有用 Accessibility 截图逐帧识别原生标题栏绘制。
