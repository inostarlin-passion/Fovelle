## 5. 事实、推断和限制

### 5.1 事实

- 测试进程在 macOS 15.7.7、Qt 6.11.1、Cocoa QPA 下通过。
- 加载文件后，测试实际读取到的 QWidget/QWindow file path 均为空。
- bundle icon 文件和 Info.plist 应用身份未被删除。
- 所有最终 JSON evidence 的 `passed` 为 `true`。

### 5.2 推断

- 根据 Qt 对 `setFilePath`/proxy icon 的定义和 Apple 对 `representedURL` 的定义，空 QWindow file path 表示不会显示文档 proxy icon。
- 窗口级 icon 清空与 bundle icon 保留的组合满足“标题栏隐藏、应用身份保留”的目标。

### 5.3 限制

- 本次未使用 Accessibility API 做屏幕像素级标题栏截图断言；系统证据以真实 Cocoa 窗口属性为主，视觉结论依赖官方映射文档。
- RSS、磁盘 I/O 和网络值受 macOS 后台活动影响；它们是本次目标负载的观测，不是所有环境的绝对上界。
