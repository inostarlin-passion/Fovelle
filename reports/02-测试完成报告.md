## 3. 实现与根因闭环

### 3.1 标题栏图标

- 删除 `QVApplication` 中的全局 `QApplication::setWindowIcon(...)`。
- `MainWindow` 构造后执行 `setWindowIcon(QIcon())`，只清除窗口 icon。
- bundle 的 `qView.icns`、Qt resource 中的 `Fovelle.png` 和 Finder/Dock 资源仍保留。
- 单元测试验证 `qvApp->windowIcon().isNull()`、`MainWindow::windowIcon().isNull()`；集成测试验证 bundle icon 文件存在。

### 3.2 滚轮缩放

- 新增纯函数 `QVGraphicsView::wheelZoomFactor()`，使步长计算可脱离平台事件投递确定性测试。
- 普通鼠标 wheel 使用符号化的一个步长；触控板/触控设备才使用 `delta / 120` fractional steps。
- `delta=240`、倍率 `1.25` 的测量结果：mouse `1.25`，fractional `1.5625`；反向 mouse 为 `0.8`。

### 3.3 WebP/AVIF 错误根因与修复

事实证据显示当前 Qt runtime 的 imageformats plugin 集合没有可用的 WebP/AVIF 解码路径，且 Qt 官方 Image Formats 文档没有 AVIF plugin；因此 `QImageReader` 返回 `UnsupportedFormatError`，其数值为 3。Apple Image I/O 在本机可查询到 WebP/AVIF UTI 并成功读取同一 fixture。

修复包含：

- 在 `qvcocoafunctions.mm` 中使用 Image I/O 运行时 UTI 查询和 CGImage 解码；不把“支持格式”静态写死为必然可用。
- 在 `QVImageLoader` 的 Qt 读取失败后，按文件后缀且仅在 Image I/O 报告支持时调用 fallback。
- 应用扩展集合合并 native WebP/AVIF；AVIF 同时注册 `.avifs` 别名，MIME 集合加入 `image/webp` 与 `image/avif`。
- `QVOptionsDialog::syncFormats()` 继续从 `getAllFileExtensionList()` 读取，因此 Settings → Formats 与文件枚举共用一个注册表。
- CMake、qmake、测试 target 均加入 CoreGraphics/ImageIO 链接。

## 6. 未覆盖项与后续建议

- 本次系统测试没有使用 Accessibility 逐帧截图确认 macOS 原生标题栏绘制；通过 Qt window icon 属性、bundle 资源和构建集成验证了同一行为链路。
- 本机 Image I/O 的 AVIF 能力由运行时 UTI 查询决定；在不支持 `public.avif` 的旧 macOS 上，代码会保持原有“不可读”语义，而不是伪造成功。
- 磁盘/网络指标是主机观测，不应作为应用单进程精确 I/O 账本。
