### 2.2 外部事实链

- qView 上游事实：项目定位为实用、极简的图片查看器，许可证为 GPL-3.0：[qView GitHub](https://github.com/jurplel/qView)。
- Bundle 身份事实：Apple 要求 `CFBundleIdentifier` 唯一，并说明 reverse-DNS 是常用格式：[Apple CFBundleIdentifier](https://developer.apple.com/documentation/bundleresources/information-property-list/cfbundleidentifier)。
- CMake 实现事实：`MACOSX_BUNDLE` 和自定义 `MACOSX_BUNDLE_INFO_PLIST` 用于 macOS Bundle：[CMake 文档](https://cmake.org/cmake/help/latest/prop_tgt/MACOSX_BUNDLE_INFO_PLIST.html)。
- Qt 身份事实：Qt 的 application/organization 属性影响命令行、版本和默认设置位置：[Qt QCoreApplication](https://doc.qt.io/qt-6/qcoreapplication.html)。
- updater API 事实：GitHub Releases 使用 `/repos/{owner}/{repo}/releases`，发布对象带 `tag_name`：[GitHub REST releases](https://docs.github.com/en/rest/releases/releases?apiVersion=latest)。
- macOS 部署事实：Qt GUI 应用使用 Bundle，`macdeployqt` 负责部署依赖：[Qt macOS Deployment](https://doc.qt.io/qt-6/macos-deployment.html)。

上述链接用于记录设计依据；它们不替代本地构建和运行证据。


`build/Fovelle.app` 存在且可执行文件可执行；`build/qview` 和 `build/qView.app` 不存在。

### 5.2 启动时间与吞吐

负载为同一机器上 30 次顺序执行 `Fovelle --version`，使用 `/usr/bin/time -p`，每次输出均为 `Fovelle 0.1.0`。

| 指标 | 实际值 | 本规格门槛 | 结论 |
|---|---:|---:|---|
| 样本数 | 30 | 30 | 满足 |
| 平均 real | 0.125 s | ≤1.000 s | 通过 |
| P99 real | 0.160 s | ≤2.000 s | 通过 |
| 最大 real | 0.160 s | ≤2.000 s | 通过 |
| 吞吐 | 7.98 次/s | ≥1 次/s | 通过 |
| 平均 user | 0.072 s | 记录项 | 已记录 |
| 平均 sys | 0.010 s | 记录项 | 已记录 |

P99 使用 `ceil(0.99 × 30)=30` 的有序样本位置，因此本次 P99 与最大值相同。此结果只说明当前 arm64 macOS 开发机在启动烟囱负载下满足门槛，不能代表图片解码、超大文件、连续窗口操作或发布机负载。

### 5.3 资源观察

一次 `/usr/bin/time -l` 采样得到：

| 指标 | 实际值 | 本规格门槛/状态 |
|---|---:|---|
| maximum resident set size | 45,645,824 bytes（43.53 MiB） | ≤256 MiB，满足 |
| swaps | 0 | 0，满足 |
| block input operations | 0 | 离线 `--version` 期望 0，满足 |
| block output operations | 0 | 离线 `--version` 期望 0，满足 |

一次约 1 秒 idle GUI 观察中，`ps` 记录 CPU 7.5%、RSS 105,952 KiB；进程随后由测试脚本以已知 PID 终止。`lsof -p` 在本机没有在限定时间返回稳定的文件句柄计数，因此句柄数为“未测量”，不作通过结论。CPU 利用率、网络 I/O 和持续存储 I/O 的正式上限未由需求提供，不能从一次启动样本推导。

## 7. 编译警告与未覆盖项

构建成功但出现来自 Qt 6.11 的弃用警告：`QCheckBox::stateChanged`、`qAsConst`、部分 `QDateTime` API，以及 macOS `NSWorkspace::absolutePathForAppBundleWithIdentifier`。这些警告不影响本次验收结果，但应作为后续兼容性维护项处理。

未覆盖项：真实 Fovelle GitHub Releases 响应、断网/限流/非 2xx updater 分支、Qt 5.15 实机编译、Apple codesign、DMG 创建、notarization、clang-format workflow、长时间图片浏览 QoS、句柄数、网络 I/O 和正式发布机阈值。上述项目均已在规格中列为边界，不作为已验证事实。
