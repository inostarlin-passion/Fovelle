# 图片导航边界缩放验收规格

| 原子验收标准 | 用例 |
|---|---|
| A01 关闭循环时，首张请求上一张保留缩放 | S01、D01 |
| A02 关闭循环时，末张请求下一张保留缩放 | S01、D02 |
| A03 单图目录请求上一张保留缩放 | S01、S02、D03 |
| A04 单图目录请求下一张保留缩放 | S01、S02、D04 |
| A05 到达非循环边界仍发送对应方向的提示信号 | D01、D02、D03、D04 |
| A06 到达非循环边界仍发送幻灯片停止信号 | D01、D02、D03、D04 |
| A07 切换到不同文件时，重置设置开启会恢复默认缩放 | D05 |
| A08 切换到不同文件时，重置设置关闭会保留当前比例 | D06 |

## S01 非循环边界提前返回（静态）

- 测试目的　验证非循环边界在查找和加载候选文件前结束。
- 前置条件　仓库源码可读，Python 可用。
- 输入数据　`QVImageCore::goToFile()` 的上一张和下一张分支以及候选文件查找逻辑。
- 操作步骤　运行 `tests/navigation_boundary_hint_static.py`，核对两方向都会在对应边界设置 `reachedEnd`，并在查找前返回该结果。
- 预期结果　两个方向的边界标记均由提前返回传递给调用方。
- 后置条件　源码和设置没有写入。

## S02 当前文件按索引判重（静态）

- 测试目的　验证候选索引等于当前文件索引时无需依赖路径拼写，且空视图仍可从保留索引打开文件。
- 前置条件　仓库源码可读，Python 可用。
- 输入数据　`QVImageCore::goToFile()` 的候选查找、同索引检查及加载调用。
- 操作步骤　运行同一静态脚本，核对候选索引查找后、加载前的返回条件。
- 预期结果　同索引且存在当前文件路径时返回。
- 后置条件　源码和设置没有写入。

## D01 首张请求上一张（动态）

- 测试目的　复现并覆盖目录首张的缩放重置。
- 前置条件　Cocoa QtTest 可运行，关闭循环，开启切图重置缩放。异拼写行需要测试文件系统接受不同大小写访问同一文件。
- 输入数据　按名称排序的两张 PNG。分别用原拼写和不同大小写的路径打开首张。
- 操作步骤　等待目录索引可用，手动设为 175%，记录视图变换，再通过主窗口请求上一张并处理异步事件。
- 预期结果　当前路径、175% 比例、手动缩放模式和变换保持一致。没有文件或缩放变更信号，收到一个上一张方向提示和一个幻灯片停止信号。
- 后置条件　关闭测试窗口，释放临时文件并还原设置。

## D03 单图目录请求上一张（动态）

- 测试目的　覆盖首末索引重合时的向前请求。
- 前置条件　Cocoa QtTest 可运行，开启切图重置缩放。循环开启的异拼写行需要测试文件系统支持大小写别名。
- 输入数据　一张 PNG。关闭循环时使用原拼写，开启循环时使用不同大小写的路径。
- 操作步骤　打开图片并等待目录索引可用，手动设为 175%，通过主窗口请求上一张并处理异步事件。
- 预期结果　当前路径、175% 比例、手动缩放模式和变换保持一致。没有文件或缩放变更信号。关闭循环时发送上一张方向提示与幻灯片停止信号各一次，开启循环时两者均为零次。
- 后置条件　关闭测试窗口，释放临时文件并还原设置。

## D05 成功切图时重置缩放（动态）

- 测试目的　验证普通切图和跨边界循环仍应用重置设置。
- 前置条件　Cocoa QtTest 可运行，开启切图重置缩放，默认模式为适合窗口。
- 输入数据　两张尺寸不同的 PNG，分别关闭和开启循环。
- 操作步骤　打开第一张并设为 175%。关闭循环时请求下一张，开启循环时请求上一张。等待第二张加载完成。
- 预期结果　两行均切换到第二张，默认适合窗口模式恢复，缩放比例离开 175%，未发送边界提示。
- 后置条件　关闭测试窗口，释放临时文件并还原设置。
