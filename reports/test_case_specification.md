# 2026-11-05 原子验收测试规格

D1–L3为10组回归用例，每组对应静态和动态测试；下表A01–A23给出不可再合并的独立验收断言及其六要素；动态用例固化在 tests/review_fixes_acceptance.inc，静态用例在 tests/review_fixes_static.py。真实 Qt/Cocoa、文件系统和HTTP路径均执行；资源异常和慢任务使用确定性替身，避免破坏用户文件。

- 操作步骤：显示A；请求B并打开删除确认；等B交付；确认。

- 后置条件：恢复/删除测试自己的垃圾桶文件；关闭窗口。

## 补充执行细节

- C1 对 alpha 使用精确比较，对8位色彩转换的RGB分量仅允许2级舍入误差；样本横跨2048分块边界，并在复制前删除源文件，验证已加载快照。
- E1 使用 sparse truncate 触发 RLIMIT_FSIZE，避免实际消耗256MiB磁盘；分别检查继承上限、失败时文件峰值、超限后标记缺失和PID已回收。E2检查持续输出与快速退出，E3执行真实30秒超时，未缩短生产阈值。
- L3分别独立保留SDR对象、HDR对象、MIME对象及Open With工作：释放其他所有引用后再断言文件存在，最后释放被测消费者并断言目录删除。HTTP失败和取消使用真实loopback网络。
- D1在真实Cocoa确认框存在时等待B图片交付并模拟标准按钮点击；垃圾桶用例只清理自己创建的临时文件。D2通过与确认入口相同的快照和事务方法检查同路径换inode、原inode修改，再单独取消确认框。
