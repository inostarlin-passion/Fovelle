## A01 Qt 控件绘制

| 要素 | S01 | D01 |
|---|---|---|
| 测试目的 | 核对控件固定使用旧深色背景分支的绘制参数 | 对真实按钮渲染取样 |
| 前置条件 | 主窗口和视图源码可读 | Cocoa 窗口及 Qt SVG 加载可用 |
| 输入数据 | 控件绘制代码和原亮度选择接口 | 白左黑右及黑左白右的 SVG，各有三个同内容文件 |
| 操作步骤 | 检查灰色底板、深灰箭头、状态透明度和旧采样路径的移除 | 打开中间文件，依次移入左右边缘，等待按钮显示和淡入结束，将按钮渲染到透明图并对底板、箭头和对侧取样 |
| 预期结果 | 样式固定，无亮度选择入口或专用缓存 | 两种配色下两侧均绘制灰色底板及方向正确的深灰箭头 |
| 后置条件 | 源码不变 | 销毁窗口和临时文件，恢复测试设置 |

## A02 原生图层绘制

| 要素 | S02 | D02 |
|---|---|---|
| 测试目的 | 核对原生路径固定使用旧深色背景分支的绘制参数 | 读取真实 Core Animation 形状图层 |
| 前置条件 | 主窗口、视图及原生渲染源码可读 | Cocoa 窗口可用，PNG 进入原生渲染 |
| 输入数据 | 视图转发接口、原生图层绘制代码 | 白左黑右及黑左白右的 PNG，各有三个同内容文件 |
| 操作步骤 | 检查原生 API 无样式参数，并检查底板填色和箭头描边 | 打开中间文件，依次移入左右边缘，等待淡入完成，读取对应的可见图层、填色、描边和路径方向 |
| 预期结果 | 固定灰色圆角底板和深灰箭头，交互状态仍可控制 alpha | 两种配色下两侧都有可见灰色底板和方向正确的深灰箭头，Qt 按钮处于隐藏状态 |
| 后置条件 | 源码不变 | 销毁窗口及图层，删除临时文件，恢复测试设置 |

## A03 合成与淡入淡出

| 要素 | S03 | D03 |
|---|---|---|
| 测试目的 | 确认两个后端仅对合成后的按钮应用动画透明度 | 逐像素验证 Qt 绘制的透明外缘及整体淡化 |
| 前置条件 | Qt 和原生绘制源码可读 | 主窗口已创建两侧按钮及动画 |
| 输入数据 | `paintOpacity` 动画目标与原生父子图层透明度 | 两侧按下态按钮在 100% 和 50% 不透明度下的图像 |
| 操作步骤 | 检查先合成后绘制的顺序及原生父图层的组透明度 | 渲染到透明图像，检查四角、底板取样点和不透明箭画像素，对照每个像素的 alpha |
| 预期结果 | 动画作用于合成后的按钮 | 四角 alpha 为 0，底板完整 alpha 为 235，箭头有不透明像素，半透明帧的 alpha 约为完整帧的一半 |
| 后置条件 | 源码不变 | 释放窗口、按钮和测试图像 |
