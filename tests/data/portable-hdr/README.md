# Portable HDR regression signals

These are original synthetic test signals, dedicated to the public domain under CC0-1.0. They contain no camera photographs or third-party source data.

- `gain-map.jpg`: 256×128 Display P3 SDR signal with an Apple-generated HDR gain map; generated by `tests/generate_portable_hdr.mm` using macOS 15+ Core Image.
- `bayer.dng`: 512×512 uncompressed 16-bit RGGB RAW with DNG 1.4 tags, generated by `tests/generate_portable_dng.py` without external packages.

`manifest.json` pins the committed byte content. Regeneration on a different macOS codec version may produce different JPEG bytes; inspect the decoded semantics and deliberately update the manifest when replacing a fixture. The synthetic DNG validates the RAW code path; vendor-specific NEF and processed DNG camera regressions remain additional local tests.
